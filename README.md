GTA VI trophy guide and tracker for all 55 PS5 trophies — an offline web app with a checklist, a roadmap to the platinum, missable flags, filters, a spoiler setting, and progress export/import. Every guide is written in our own words and cites its sources beside it; names, descriptions and grades are exactly as PlayStation publishes them.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
